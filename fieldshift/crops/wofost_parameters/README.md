# WOFOST crop parameters (bundled)

Crop parameter files for WOFOST 7.2, copied unchanged from
[ajwdewit/WOFOST_crop_parameters](https://github.com/ajwdewit/WOFOST_crop_parameters),
branch `wofost72`, commit `fc6eda46ea0081eb0ad31fa92ea49fea60e11075`.

Copyright Wageningen Environmental Research, Wageningen-UR; licensed under
the **EUPL 1.2** (see `LICENSE` in this folder). They are bundled so crop
simulations work without downloading them. To update, copy the files of the
same branch again and change the commit above.

Read by `fieldshift/crops/wofost_crops.py` (PCSE `YAMLCropDataProvider`).
