# Languages (i18n)

Every text the user reads comes from a JSON file in `fieldshift/i18n/`, one
per language:

```
fieldshift/i18n/
├── __init__.py   tr(), set_language(), available_languages()
├── en.json       English (default, and fallback for missing keys)
└── es.json       Spanish
```

Each file is a flat `"key": "text"` map. Texts may have `{placeholders}`:

```json
"fields.export_done": "{count} field(s) exported to {path}"
```

In code, ask for the text by key, never write it directly:

```python
from fieldshift.i18n import tr

button = QtWidgets.QPushButton(tr("fields.draw"))
label.setText(tr("fields.export_done", count=3, path=path))
```

## Choosing the language

```bash
FIELDSHIFT_LANG=es make run
```

Default: `en`. Widgets read their texts when they are built, so the language
is chosen at start-up.

## Adding a text or a language

- **New text**: add the key to `en.json` **and** to every other language file.
  `tests/test_i18n.py` fails if a file is missing a key.
- **New language**: copy `en.json` to `<code>.json` (e.g. `pt.json`) and
  translate the values, not the keys.
- Keys are grouped by feature with a prefix: `common.*`, `layers.*`,
  `fields.*`.

Texts written before this module (header, Position and Tools boxes) are
still in English in the code; move them here when you touch them.
